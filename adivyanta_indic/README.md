# Adivyanta Indic scratch GPT

This directory contains Adivyanta's randomly initialized 46,349,312-parameter GPT checkpoint and its 16,384-token byte-level BPE tokenizer. No pretrained model weights were used. The first phase used 120,449 English, Hindi, Hinglish, and smaller amounts of other Indian-language training pairs. The expanded phase adds 134,379 training pairs from additional Hindi Aya, UltraChat, and GSM8K selections. See the repository [README](../README.md), [first preparation script](../prepare_indic_data.py), [expanded preparation script](../prepare_expanded_data.py), and the two manifests for exact sources, licenses, and selection rules.

`best.pt` is selected by mixed-source validation loss on the first corpus when reproducing training; it is kept local. `expanded/best.pt` continues from those scratch weights and is selected on the expanded validation set. `expanded/chat_best.pt` continues the expanded weights on conversational examples and is selected using a separate chat validation slice. The two expanded checkpoints ship in GitHub. Metric JSON files report the measured losses. The interactive app routes Roman Hindi to the expanded chat checkpoint and English/Devanagari to the expanded base when both are available; it can further load a user-specific `data/personalized.pt` after explicit `/correct` feedback training. That personalized file is local and never included here.

The model has 12 decoder layers, eight attention heads, 512 hidden dimensions, 256-token context, tied input/output embeddings, and causal attention. Each target reply token is trained with next-token cross-entropy. Prompts are visible to the network but are masked out of the loss. The weights are stored in half precision to make the repository checkpoint smaller; loading into the model restores standard inference behavior.

This is an experimental small model. It can repeat text, mix languages, hallucinate, and mishandle sensitive requests. English/Hindi/Hinglish are main targets; other language exposure is too small to claim reliable support. Neither low loss nor polished lines from the app's authored roast fallback prove broad intelligence. Check [model-only benchmark outputs](../benchmarks/indic_model_outputs.jsonl) and the expanded outputs when available. No Qwen-level or state-of-the-art claim is supported by the present evidence.
